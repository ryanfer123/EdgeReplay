A value is only part of the story

Keep the context
beside the signal.

A carried-forward CAN value is different from a fresh update. A unit mismatch is different from a surprising reading. EdgeReplay makes those distinctions visible.

Open an investigation

Time stays attached.

CAN frame order is preserved even when timestamps repeat. The inspector shows how old a channel value was at the selected frame.

Units stay explicit.

Known channels carry declared units. Unknown channels remain unitless, and out-of-range values get notices rather than silent corrections.

Exports keep the record.

Save the parsed session, source fingerprint, contracts, and label comparison as JSON, or export an importable CSV.

Start with the format you already record. The first release supports numeric signals and one explicit CAN driver profile.

Up to 20,000 rows and 3 MiB per recording. Up to 12 numeric signal channels.

One row per sample.

Time is in milliseconds and strictly increasing. Every channel value must be numeric and finite.

can-frames.csvDownload example 
time_ms,can_id,data_hex
0,0x300,0000704100002041
0,0x301,00000c430000803e
1,0x302,0000003f00000000
Eight bytes. Two floats.

The included profile decodes IDs 0x300–0x302 as little-endian float pairs. Repeated timestamps keep source order. This is not a general DBC parser.

Before you open a trace

A few useful
distinctions.

Clear limits make a better instrument.

Does replay send data to my device?+

No. Replay moves through a recorded file in the browser. It does not connect to a CAN bus, transmit frames, or control hardware. Browser-clock playback is not a real-time timing guarantee.

Does EdgeReplay run my model?+

No. The prediction panel compares expected_label and predicted_label columns already present in a signal CSV. It reports agreement and disagreement locations. It does not execute uploaded code or establish accuracy on an independent test set.

Can I inspect my own channels?+

Yes. Use a time_ms column and up to 12 numeric channel columns. Recognized names get declared units; other names remain unitless. Missing numeric values and malformed rows are rejected instead of filled with guesses.

Where are my recordings saved?+

When run locally, recordings stay in SQLite on your computer. The hosted workspace keeps active recordings temporarily in your browser session. Export a file or sign in through Cloud to save a private Supabase copy before closing the hosted session. Cloud copies are optional.

Can I use it without a browser?+

The Python command-line inspector validates a CSV and exports a parsed JSON recording: python -m edge_replay --inspect recording.csv --output recording.json. The interactive replay workspace needs JavaScript.
